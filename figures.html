科研绘图

论文级图表示例 · 可直接复制的 matplotlib 模板 · 配色与工具素材

图例速览

按论文结构分三组，图表类型标注在每条标题里。每张图附完整可运行的 matplotlib 代码，点开「查看代码」复制即用。配色统一采用 Okabe-Ito 色盲友好方案。

顶会 Pipeline 案例解剖

以下五张是简化重绘的示意图（原图版权归属各论文），分析只谈绘图技法：构图、流向、配色、抽象粒度。所有手法都能用 matplotlib 或 draw.io 复现。

P1InstructGPT（NeurIPS 2022）：三幕式流程

RLHF 三阶段图是近年被引用最多的 pipeline 图之一，结构极简却信息完整。

  1. 构图即叙事。三幕横向编号，阅读顺序与训练顺序一致；阶段之间用浅灰底块分隔，替代显式大箭头。
  2. 抽象粒度只到「谁先谁后」。每幕仅 2 到 3 个框，模型内部结构、超参全部让给正文。
  3. 箭头语义分层。实线表示数据流，虚线表示参数更新，两种箭头构成全部图例，读者零成本解码。
  4. 颜色守恒。Prompt（蓝）、RM（橙）、策略（绿）三个角色跨幕固定颜色，视线可追踪。

P2BERT（NAACL 2019）：双联并置

预训练与微调画成左右镜像双子图，用「图元复用」表达参数共享，是双阶段方法的标准画法。

  1. 双联并置表达「同一架构两阶段」。左右子图共享图元、尺寸与坐标，读者视线自动对齐，差异只剩顶部任务头。
  2. 图元复用替代文字。「参数共享」靠画成一模一样来表达，比加一行注释更直接。
  3. 单点高亮讲机制。掩码 token 是全场唯一暖色块，MLM 机制无需文字即可定位。

P3Transformer（NeurIPS 2017）：对称双塔

被引超十万的架构图。对称构图中唯一的斜线就是创新点，值得逐像素学习。

  1. 对称构图制造反差。双塔垂直镜像、走线全部竖直，全场唯一的两条斜线恰好落在 cross-attention 上，视觉焦点即论文创新点。
  2. N× 角标折叠重复。6 层堆叠收进一个圆角块加角标，密度骤降，结构感保留。
  3. 流向与阅读方向一致。数据自下而上，输入在下、输出在顶，读者不需要方向图例。
  4. 次要元素降饱和度。Add & Norm 只用一行小字带过，线稿浅灰，不抢主体的戏。

P4CLIP（ICML 2021）：双流汇聚

双流编码加相似度矩阵的构图被后续所有对比学习论文沿用，矩阵本身就是结果的可视化。

  1. 双流镜像构图。图像流与文本流上下对称，汇聚到右侧矩阵，对比关系由几何位置直接表达。
  2. 颜色即模态。蓝色全程代表图像、橙色全程代表文本，两个角色在任何子图里都不会混淆。
  3. 矩阵自解释。对角线深色块直接编码「正样本在对角」，替代整段文字说明。
  4. 编码器画成黑盒。贡献点在学习目标而非架构，内部结构留白，图面带宽全给对比关系。

P5DDPM（NeurIPS 2020）：双向链式

扩散模型的链式图把「状态随时间演化」直接演在节点里，前向与反向两个过程零交叉共存。

  1. 链式构图表达马尔可夫性。等距节点加同构箭头，读者一眼看出「每步只依赖上一步」。
  2. 两个过程上下分行。前向走上排实线向右，反向走下排虚线向左，方向、线型、颜色三重区分，零交叉。
  3. 节点填充直接演状态。从实色渐变到空白的填充即「逐渐变噪」的具象化，读者无需图例。
  4. 可学习部分单独着色。只有 p_θ 用主色，标出模型真正要学的部分，其余皆是灰色固定过程。

06Scaling 分析（对数轴散点 + 拟合线）

参数量与指标的幂律关系是对数轴散点的经典场景。散点给原始观测，直线给拟合趋势，log-log 坐标下幂律天然呈直线。

查看 matplotlib 代码 
import numpy as np
import matplotlib.pyplot as plt

params = np.array([0.3, 1, 3, 10, 30, 90])
loss_a = np.array([3.60, 3.20, 2.90, 2.65, 2.45, 2.30])
loss_b = np.array([3.90, 3.60, 3.30, 3.05, 2.85, 2.70])

def fit_line(p, l):
    k, b = np.polyfit(np.log10(p), l, 1)
    xs = np.logspace(np.log10(p.min()), np.log10(p.max()), 50)
    return xs, k * np.log10(xs) + b

fig, ax = plt.subplots(figsize=(3.5, 2.6))
ax.scatter(params, loss_a, s=16, color="#0072B2", zorder=3,
           label="Compute-optimal")
ax.scatter(params, loss_b, s=16, marker="s", color="#E69F00",
           zorder=3, label="Under-trained")
ax.plot(*fit_line(params, loss_a), color="#0072B2", lw=1.4)
ax.plot(*fit_line(params, loss_b), color="#E69F00", lw=1.4)

ax.set_xscale("log")
ax.set_xlabel("Parameters (B)")
ax.set_ylabel("Validation Loss")
ax.set_ylim(2.0, 4.1)
ax.spines[["top", "right"]].set_visible(False)
ax.grid(axis="y", lw=0.6, color="#e5e9ee")
ax.set_axisbelow(True)
ax.legend(loc="lower left")
fig.savefig("fig_scaling.pdf")

10精度与延迟权衡（帕累托前沿）

部署场景的标准叙事图。前沿线上的模型才有资格进对比表，灰色区域的点被直接淘汰。左上是更好的方向，阴影标出被支配区域。

查看 matplotlib 代码 
import numpy as np
import matplotlib.pyplot as plt

# (latency_ms, accuracy)
models = [
    (40, 88.0), (60, 90.0), (90, 91.5), (150, 92.8), (260, 93.5),
    (120, 89.0), (180, 90.5), (230, 91.0), (100, 87.0), (300, 92.0),
]

def pareto_front(points):
    front, best = [], -np.inf
    for x, y in sorted(points):
        if y > best:
            front.append((x, y))
            best = y
    return front

front = pareto_front(models)
fx, fy = zip(*front)
lat = [m[0] for m in models]
acc = [m[1] for m in models]

fig, ax = plt.subplots(figsize=(3.5, 2.8))
ax.fill_between(fx, fy, 86, color="#f0f1f3", zorder=1)
ax.scatter(lat, acc, s=26, c="#BBBBBB", zorder=2,
           label="Dominated")
ax.plot(fx, fy, ls="--", color="#D55E00",
        linewidth=1.2, zorder=3)
ax.scatter(fx, fy, s=36, c="#0072B2", zorder=4,
           label="Pareto front")
ax.set_xlabel("Latency (ms)")
ax.set_ylabel("Accuracy (%)")
ax.set_ylim(86, 94.5)
ax.legend(loc="lower right")
ax.grid(linewidth=0.5, alpha=0.4)
ax.set_axisbelow(True)
ax.spines[["top", "right"]].set_visible(False)
fig.savefig("fig_pareto.pdf")

项目规范说明
单栏图宽figsize=(3.5, h)IEEE / ACM 单栏 3.5 in（约 8.9 cm）
双栏图宽figsize=(7.16, h)通栏大图 7.16 in（约 18.2 cm）
图高上限≤ 9.2 in超过会被排版系统压缩
线图格式.pdf / .svg矢量优先，缩放不失真
位图分辨率dpi=300热图、照片类 300 起步，投稿常要求 600
字体嵌入pdf.fonttype=42Type 3 字体会被多数出版方拒收
图内字号7 ~ 9 pt与正文 caption 字号一致，插入后不再缩放

实用技巧

  1. 先定物理尺寸再画图。用 figsize 锁定最终插入论文的尺寸，字号就不会在排版时缩放失真。
  2. 弱化装饰。隐藏上、右脊线（spines），网格只留 y 方向细线并压到数据层下方（set_axisbelow(True)）。
  3. 配色先过色盲关。默认用 Okabe-Ito 方案，避免红绿直接对比；梯度数据用单色深浅渐变。
  4. 误差展示用阴影带。fill_between 画置信区间比 errorbar 的密针脚干净得多。
  5. 图内只留图例。标题和结论写进 LaTeX 的 \caption{}，图内标题一律省略。
  6. 组内顺序全篇统一。方法颜色、柱序、线型在所有图里保持同一映射，读者只需记一次图例。
