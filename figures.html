import matplotlib.pyplot as plt
from matplotlib.patches import FancyBboxPatch, Rectangle

def block(ax, x, y, w, h, text, fc="#f6f8fa", ec="#d0d7de"):
    ax.add_patch(FancyBboxPatch((x, y), w, h,
                                boxstyle="round,pad=0.05",
                                facecolor=fc, edgecolor=ec))
    ax.text(x + w / 2, y + h / 2, text,
            ha="center", va="center", fontsize=9.5)

fig, ax = plt.subplots(figsize=(3.5, 4.6))

顶会 Pipeline 案例解剖

以下十张是简化重绘的示意图（原图版权归属各论文），分析只谈绘图技法：构图、流向、配色、抽象粒度。所有手法都能用 matplotlib 或 draw.io 复现。

👉 想看 原始论文里的真图？已整理 14 张案例库 · 按构图类型分组 →

P1InstructGPT（NeurIPS 2022）：三幕式流程

›

RLHF 三阶段图是近年被引用最多的 pipeline 图之一，结构极简却信息完整。

  1. 构图即叙事。三幕横向编号，阅读顺序与训练顺序一致；阶段之间用浅灰底块分隔，替代显式大箭头。
  2. 抽象粒度只到「谁先谁后」。每幕仅 2 到 3 个框，模型内部结构、超参全部让给正文。
  3. 箭头语义分层。实线表示数据流，虚线表示参数更新，两种箭头构成全部图例，读者零成本解码。
  4. 颜色守恒。Prompt（蓝）、RM（橙）、策略（绿）三个角色跨幕固定颜色，视线可追踪。

P2BERT（NAACL 2019）：双联并置

›

预训练与微调画成左右镜像双子图，用「图元复用」表达参数共享，是双阶段方法的标准画法。

  1. 双联并置表达「同一架构两阶段」。左右子图共享图元、尺寸与坐标，读者视线自动对齐，差异只剩顶部任务头。
  2. 图元复用替代文字。「参数共享」靠画成一模一样来表达，比加一行注释更直接。
  3. 单点高亮讲机制。掩码 token 是全场唯一暖色块，MLM 机制无需文字即可定位。

P3Transformer（NeurIPS 2017）：对称双塔

›

被引超十万的架构图。对称构图中唯一的斜线就是创新点，值得逐像素学习。

  1. 对称构图制造反差。双塔垂直镜像、走线全部竖直，全场唯一的两条斜线恰好落在 cross-attention 上，视觉焦点即论文创新点。
  2. N× 角标折叠重复。6 层堆叠收进一个圆角块加角标，密度骤降，结构感保留。
  3. 流向与阅读方向一致。数据自下而上，输入在下、输出在顶，读者不需要方向图例。
  4. 次要元素降饱和度。Add & Norm 只用一行小字带过，线稿浅灰，不抢主体的戏。

P4CLIP（ICML 2021）：双流汇聚

›

双流编码加相似度矩阵的构图被后续所有对比学习论文沿用，矩阵本身就是结果的可视化。

  1. 双流镜像构图。图像流与文本流上下对称，汇聚到右侧矩阵，对比关系由几何位置直接表达。
  2. 颜色即模态。蓝色全程代表图像、橙色全程代表文本，两个角色在任何子图里都不会混淆。
  3. 矩阵自解释。对角线深色块直接编码「正样本在对角」，替代整段文字说明。
  4. 编码器画成黑盒。贡献点在学习目标而非架构，内部结构留白，图面带宽全给对比关系。

P5DDPM（NeurIPS 2020）：双向链式

›

扩散模型的链式图把「状态随时间演化」直接演在节点里，前向与反向两个过程零交叉共存。

  1. 链式构图表达马尔可夫性。等距节点加同构箭头，读者一眼看出「每步只依赖上一步」。
  2. 两个过程上下分行。前向走上排实线向右，反向走下排虚线向左，方向、线型、颜色三重区分，零交叉。
  3. 节点填充直接演状态。从实色渐变到空白的填充即「逐渐变噪」的具象化，读者无需图例。
  4. 可学习部分单独着色。只有 p_θ 用主色，标出模型真正要学的部分，其余皆是灰色固定过程。

P6ViT（ICLR 2021）：patch 网格化流水线

›

「一张图等于 16×16 个词」的成名图：把二维图像折叠成一维 token 序列，矩阵到序列的降维全靠图元平铺表达。

  1. 图元平铺即降维。左侧 3×3 网格与右侧 1×9 序列画的是同一组方块，位置重排表达「矩阵展平成序列」，一个字解释都不用。
  2. 单块高亮引导视线。九块蓝灰阶里只有一块橙色，读者第一眼落在「单个 patch 如何被编码」，随后的连线自己就能完成。
  3. 特殊 token 插队。class embedding（0*）排在序列首位却画成空心白底，与实心 patch 区分，「额外插入的」身份一眼可辨。
  4. 颜色只分两类。数据通路一律蓝灰系，可学习模块（Encoder、MLP 头）用主色描边，全图维持「数据 vs 模块」两个色系。

P7GPT-3（NeurIPS 2020）：缩放曲线族（小倍数图）

›

few-shot 缩放的招牌图：同构坐标的小面板平铺，一张图同时回答「规模涨有没有用」与「不同任务涨幅差多少」。

  1. 小倍数图摊开异质性。每个任务独立面板、共享坐标，任务间的差异与共同的上升趋势同屏呈现，聚合均值会抹掉的细节全部保留。
  2. 三种条件的编码跨面板恒定。few-shot 粗蓝、one-shot 橙、zero-shot 灰虚线，全图共用一套图例，读者解码一次看全场。
  3. 对数横轴是缩放叙事的刚需。参数量横跨三个数量级，log 轴让 125M 到 175B 等距铺开，曲线形态才可比。
  4. 让斜率自己说话。不加趋势注释，所有面板里 few-shot 曲线的斜率都显著大于 zero-shot，「示例越多涨得越快」由视觉直接给出。

P8DPO（NeurIPS 2023）：繁简对照（垂直双联）

›

回应「你的算法太复杂」最有力的方式：上下两栏管线图，上栏 RLHF 框多线绕，下栏 DPO 一条线走完，复杂度对比不证自明。

  1. 垂直双联做减法论证。上下两栏同宽同起点，唯一变量是中间环节的数量，读者的眼睛会自动数框。
  2. 框数即复杂度。RLHF 栏五个框加两个回路，DPO 栏两个框一条直线，「省掉显式奖励模型」的主张由图面本身完成。
  3. 被删模块留残影。DPO 框里保留「奖励内嵌」字样，对应上栏的奖励模型框，暗示两条路线数学等价，删的只是显式建模步骤。
  4. 颜色随栏收敛。上栏蓝橙绿三色齐上阵，下栏单绿贯穿，繁简对比在色彩上再叠一层证据。

P9Switch Transformer（JMLR 2022）：路由分流

›

稀疏 MoE 的入门图：token 进 Router，从一排同构 expert 里点亮一个，其余保持灰虚线，「每 token 只走一条路」由图面自明。

  1. 分流靠颜色对号。两个 token 两种颜色，各自命中的 expert 同色点亮，多 token 并行的路由关系无需逐条箭头注释。
  2. expert 图元完全同构。四个专家框同尺寸同圆角，差异只在被选中的实色填充与未选的虚线描边，「可互换」是稀疏路由的前提，图元必须表达它。
  3. 左右对照定义「稀疏」。左栏所有 token 挤一个共享 FFN，右栏每 token 只点亮一个 expert，密集与稀疏的参数效率差异一眼分野。
  4. Router 是唯一深色块。全图浅色调里 Router 用深底反色，强调「决策发生在这里」，视觉焦点与机制焦点重合。

P10Chain-of-Thought（NeurIPS 2022）：提示对照

›

一道食堂算术题左右开箱：左边标准提示一步答错，右边思维链分步答对，CoT 的全部卖点压缩在两个输出框的高度差里。

  1. 用真实样例代替抽象框图。prompt 与输出都是论文原文摘录的算术题，读者的代入感比任何示意框都强，行为对比类论文的首选画法。
  2. 正误用颜色终判。错误答案配红叉，正确答案配绿勾，全图唯一的强对比色留给「结论行」，视觉权重即论证权重。
  3. 输出框高度即证据。左边一行右边五行，中间步骤的「存在性」由版面高度直接给出，无需任何强调性文字。
  4. 双联共享同一个问题。两侧 prompt 框逐字相同，唯一变量是提示方式，对照实验的受控思想平移到了图面。

›

多方法对比的主图。主线用实线加置信带，基线用虚线压低视觉权重，读者一眼锁定你的方法。

import numpy as np
import matplotlib.pyplot as plt

epochs = np.arange(0, 51)
okc = 34.4 - (34.4 - 15.6) * (1 - np.exp(-epochs / 8))
qa = 34.4 - 6.4 * (1 - np.exp(-epochs / 20))

06Scaling 分析（对数轴散点 + 拟合线）

›

参数量与指标的幂律关系是对数轴散点的经典场景。散点给原始观测，直线给拟合趋势，log-log 坐标下幂律天然呈直线。

查看 matplotlib 代码 
import numpy as np
import matplotlib.pyplot as plt

params = np.array([0.3, 1, 3, 10, 30, 90])
loss_a = np.array([3.60, 3.20, 2.90, 2.65, 2.45, 2.30])
loss_b = np.array([3.90, 3.60, 3.30, 3.05, 2.85, 2.70])

def fit_line(p, l):
    k, b = np.polyfit(np.log10(p), l, 1)
    xs = np.logspace(np.log10(p.min()), np.log10(p.max()), 50)
    return xs, k * np.log10(xs) + b

fig, ax = plt.subplots(figsize=(3.5, 2.6))
ax.scatter(params, loss_a, s=16, color="#0072B2", zorder=3,
           label="Compute-optimal")
ax.scatter(params, loss_b, s=16, marker="s", color="#E69F00",
           zorder=3, label="Under-trained")
ax.plot(*fit_line(params, loss_a), color="#0072B2", lw=1.4)
ax.plot(*fit_line(params, loss_b), color="#E69F00", lw=1.4)

ax.set_xscale("log")
ax.set_xlabel("Parameters (B)")
ax.set_ylabel("Validation Loss")
ax.set_ylim(2.0, 4.1)
ax.spines[["top", "right"]].set_visible(False)
ax.grid(axis="y", lw=0.6, color="#e5e9ee")
ax.set_axisbelow(True)
ax.legend(loc="lower left")
fig.savefig("fig_scaling.pdf")

07混淆矩阵（热力图）

›

矩阵类数据的标配。单色渐变比彩虹色更专业，数值直接写进格子，色条只作辅助参照。

部署场景的标准叙事图。前沿线上的模型才有资格进对比表，灰色区域的点被直接淘汰。左上是更好的方向，阴影标出被支配区域。

查看 matplotlib 代码 
import numpy as np
import matplotlib.pyplot as plt

# (latency_ms, accuracy)
models = [
    (40, 88.0), (60, 90.0), (90, 91.5), (150, 92.8), (260, 93.5),
    (120, 89.0), (180, 90.5), (230, 91.0), (100, 87.0), (300, 92.0),
]

def pareto_front(points):
    front, best = [], -np.inf
    for x, y in sorted(points):
        if y > best:
            front.append((x, y))
            best = y
    return front

front = pareto_front(models)
fx, fy = zip(*front)
lat = [m[0] for m in models]
acc = [m[1] for m in models]

fig, ax = plt.subplots(figsize=(3.5, 2.8))
ax.fill_between(fx, fy, 86, color="#f0f1f3", zorder=1)
ax.scatter(lat, acc, s=26, c="#BBBBBB", zorder=2,
           label="Dominated")
ax.plot(fx, fy, ls="--", color="#D55E00",
        linewidth=1.2, zorder=3)
ax.scatter(fx, fy, s=36, c="#0072B2", zorder=4,
           label="Pareto front")
ax.set_xlabel("Latency (ms)")
ax.set_ylabel("Accuracy (%)")
ax.set_ylim(86, 94.5)
ax.legend(loc="lower right")
ax.grid(linewidth=0.5, alpha=0.4)
ax.set_axisbelow(True)
ax.spines[["top", "right"]].set_visible(False)
fig.savefig("fig_pareto.pdf")

实图绘制方法论

上面的图例与案例解剖回答「好图长什么样」，这一节回答「怎么亲手画出来」。覆盖从白纸到投稿成稿的全过程，所有纪律与数据均有出处，来源附在节末。

想看真实论文原图（顶会截图）按构图类型分组的案例库，见 /pipeline/（15 张真图案例库）。

五步工作流

  1. 定主张。动笔前用一句话写下「这张图要让读者记住什么」。这句话是所有取舍的裁判，删元素、选配色、定布局时都要回来对表。（Rougier 2014, Rule 2）
  2. 纸笔草图三版。只画方框和箭头，每版五分钟，比的是布局而非细节；纸笔的修改成本最低，最适合快速试错。（Wong 2012「Pencil and paper」）
  3. 选工具、开网格。按图型选工具（见下表），打开 8px 对齐网格；模块间距统一取网格倍数（8/16/24px），视线才能扫出层级。
  4. 先形后字。精绘顺序：布局框架 → 模块形状 → 连线箭头 → 最后才填文字。文字永远最后放，避免为迁就标签而破坏布局。
  5. 缩放盲测。导出 PDF 缩到最终栏宽（单栏 3.5 in / 双栏 7.16 in）后打印或投屏检查字号；再请同事 5 秒盲测，说不出图的主张就回炉。

实例走查：画一张三阶段训练 Pipeline

以 P1（InstructGPT 风格）为例，五步走一遍，照抄即可迁移到自己的方法图。

  1. 主张：「标注反馈把基座模型逐步变成听话的助手」，阶段递进是叙事主轴，奖励模型居中承接。
  2. 草图：第一版横向单行（太宽），第二版三行堆叠（流向来回拐），第三版定稿：三幕从左到右，每幕上下两层。
  3. 工具：draw.io 开 8px 网格；模块统一高度、圆角 4px、水平间距 16px，一套参数贯穿全图。
  4. 先形后字：先摆全部模块与连线，箭头分实线（数据流）与虚线（训练更新），最后填模块名与损失标签。
  5. 盲测：缩到 3.5 in 栏宽，请同事 5 秒复述；能说出「三步训练、中间学奖励」即通过，否则回去删元素。

工具选型

工具最适合优点代价与导出

十条绘图纪律

  1. 一图一主张。图相当于论文里的一个段落，只有一个中心句；一张图想讲两件事，先拆再画。
  2. 箭头是动词。实线表数据流，虚线表梯度回传或参数更新，线宽表数据量级；全图共用一套箭头词汇表，语义变了样式就要变。（Wong 2011「Arrows」）
  3. 颜色守恒。一个角色全篇只占一个颜色，图例、正文、后续图表全部沿用；彩色留给主角，配角一律灰阶。（Wong 2010「Color coding」）
  4. 色盲安全。北欧裔人群约 8% 的男性有红绿色觉缺陷，论文落到三位北欧裔男性审稿人手里，至少一位色盲的概率约 22%；默认 Okabe-Ito，红绿同图必自查。（Wong 2011「Color blindness」）
  5. 彩虹色阶禁用。jet / rainbow 亮度不均匀，会把平滑梯度画出假边界，引入的视觉误差可超过数据总变差的 7%；梯度数据换感知均匀色阶。（Crameri 2020）
  6. 重复即折叠。三层相同模块画一层加 N× 角标，省略号与黑盒包装都是合法减法；折叠前先展开一例给读者校验。
  7. 留白是信息。非重点组件画成黑盒；每轮迭代删一个元素，删掉后主张不受损就永久删除，不承载信息的墨水都是成本。（Tufte 的 data-ink 原则；Wong「Negative space」）
  8. 字号守底线。先定最终物理尺寸再动笔（单栏 3.5 in、双栏 7.16 in），成稿缩放后图内文字与 caption 同级（约 7~9 pt），插入论文后不再缩放。
  9. 对齐成模数。间距、圆角、线宽取同一基数的倍数（如 4/8/16 px）；对齐产生免费的秩序感，错位产生昂贵的混乱。
  10. 矢量优先。框图与曲线一律 PDF / SVG，位图只留给热力图与照片；导出后检查字体嵌入，matplotlib 记得 pdf.fonttype=42。

投稿前自查清单

  • 缩放到最终栏宽后打印，最小字号可读、细线不断
  • 灰度打印仍能区分所有系列（顺带覆盖色盲场景）
  • 配色、图例、缩写与正文及前后图完全一致
  • caption 自足，不读正文也能复述图的主张
  • 误差类型写明（SEM / SD、运行次数）
  • 矢量文件字体已嵌入，位图分辨率不低于 300 dpi
  • 图内每个数值能对回实验日志

实用技巧

  1. 先定物理尺寸再画图。用 figsize 锁定最终插入论文的尺寸，字号就不会在排版时缩放失真。
  2. 弱化装饰。隐藏上、右脊线（spines），网格只留 y 方向细线并压到数据层下方（set_axisbelow(True)）。
  3. 配色先过色盲关。默认用 Okabe-Ito 方案，避免红绿直接对比；梯度数据用单色深浅渐变。
  4. 误差展示用阴影带。fill_between 画置信区间比 errorbar 的密针脚干净得多。
  5. 图内只留图例。标题和结论写进 LaTeX 的 \caption{}，图内标题一律省略。
  6. 组内顺序全篇统一。方法颜色、柱序、线型在所有图里保持同一映射，读者只需记一次图例。
